# 圆圈待办：手环原型0.1.0

本版是独立Vela应用候选，不是网页安装到手环。包名`com.local.codex.quicktodo`，独立开发签名及存储键。未修改或替换生活记录应用，未安装真机。

## 实现

- 32个事项，大小代表演示重要性，圆圈在中心向周围铺开；四向拖动，松手就近居中。尺寸配置仍为示例，尚无腕上优先级编辑界面。
- 未激活圆圈背景和图形均为黑白，激活后使用各自的彩色背景、白色图形与状态点。统一以OKLCH亮度/彩度生成32个不同色相，避免随机饱和度；屏幕实际色彩待真机确认。
- 本地图标PNG由本机字体离线渲染，避免依赖手环Emoji字体。不含用户附件或下载失败的第三方资源。
- 开启和取消分别追加唯一ID、序号、时间与原时区；显示已保存前先写入并回读校验。最多100条，满后拒绝新增，未实现清理；写入失败或结果未知时停止后续写入，不静默覆盖。
- 主界面可切换查看最近5条日志，存储保留全部事件。本版没有导出、手机接收器适配或电脑自动传输；界面明确显示“尚未传输”。
- 拖动阈值为9个设计坐标单位；四向滑动与系统返回手势的冲突、栈容器裁切、触摸事件顺序、字体及耗电仍待实机验证。吸附当前为位置更新，原生平滑吸附动画尚未单独实现。

## 构建与恢复

本机`node_modules`是指向生活记录既有固定版本工具链的目录联接，仅复用依赖；不要在该联接上执行npm install/ci或升级依赖。新设备在没有此联接的独立目录中，使用本项目package-lock.json安装依赖。构建使用aiot-toolkit 2.0.5、JSC 1.0.10。新工程的sign目录保存独立开发身份，不进入Git或Vault；保留它用于以后覆盖更新。

本机执行：`node --test tests/native.test.cjs`、`node tools/build.cjs`、`python tools/inspect_package.py`。构建在经过验证的系统临时英文目录运行，最终产物进入dist，证据为dist/build-info.json。工具的退出0本身不算成功，脚本检查实际RPK、字节码和ZIP内容。构建工具参考并复用本人的Codex生活记录工程，不使用WorkBuddy业务代码或旧密钥。

图标与配置生成：`python tools/prepare-native.py`、`python tools/prepare-icons.py`。前者同步原型色板与原生布局，后者需要本机Pillow与Windows字体；生成后的PNG已随源码存在，不要求构建机装字体。浏览器原型由`python tools/build-preview.py`生成。

## 安装后的验收步骤（待本人批准安装后执行）

1. 以独立应用安装，生活记录保持原状；不得为安装清除已有数据。若工具要求卸载原生活记录，停止。
2. 确认32事项页面可显示；四个方向滑动，松手居中；滑动过程中不开启或取消。
3. 依次激活Codex和背包，确认分别出现彩色；取消Codex恢复黑白，日志保留三条。
4. 退出重开确认背包仍激活、三条历史保留。若保存失败，不按“数据已清空”处理，不清数据重装。
5. 检查边缘事项、系统返回手势、连续快速操作、日志页返回及应用立即退出时的结果。不以构建或浏览器结果代替上述步骤。

## 2026-11-09 0.1.1真机回归与0.1.2候选
